# seed-db

Заполняет локальную БД тестовыми данными для разработки.

## Когда использовать

- "наполни базу тестовыми данными"
- "сделай seed"
- "нужны примеры для разработки"
- после `/run-migrations` на пустой БД

## Что создать

1. **Один суперадмин**:
   - username: `admin`
   - password: `admin123` (bcrypt-хеш)
   - role: `superadmin`
2. **Один контент-менеджер** (для тестирования RBAC):
   - username: `manager`
   - password: `manager123`
   - role: `content_manager`
   - Привязан к 1-2 разделам через `admin_section_permissions`
3. **3-4 раздела верхнего уровня** с подразделами:
   - "Кафедры" → "Кафедра экономики", "Кафедра менеджмента", "Кафедра языков"
   - "Учебники" (без подразделов)
   - "Научные труды" → "Монографии", "Диссертации"
   - На 3 языках (можно тестовый текст: "Каф. экономики (TM)", "Каф. экономики (RU)", "Caf. economics (EN)")
4. **10-15 книг** распределённых по разным разделам (некоторые в нескольких разделах сразу для проверки M:N):
   - Реальные PDF не нужны — указать тестовый путь
   - Метаданные на одном языке книги (поле `language`)
5. **1-2 периодических издания** + по 3-4 выпуска:
   - 1 газета, 1 журнал
6. **3-5 новостей**
7. **2-3 виртуальные подборки** (с привязанными книгами)
8. **5 FAQ** в 2 категориях
9. **2 статичные страницы** ("О библиотеке", "Контакты")
10. **site_settings** — дефолтное название и цвета института

## Где разместить

- SQL-скрипт: `/api/migrations/seed.sql` (или отдельный `/api/cmd/seed/main.go`)
- НЕ как часть основных миграций — seed запускается отдельной командой

## Использование

```sh
make seed                                          # из Makefile
# или
psql $DB_URL -f api/migrations/seed.sql
# или
go run ./api/cmd/seed
```

## Идемпотентность

Seed должен быть **идемпотентным** — повторный запуск не должен ломать БД. Использовать `INSERT ... ON CONFLICT DO NOTHING` или предварительный `TRUNCATE` всех таблиц (для dev-окружения).

## После seed

- Напомнить пользователю учётные данные:
  - admin / admin123 (суперадмин)
  - manager / manager123 (контент-менеджер с ограниченным доступом)
