# Changelog

Все значимые изменения платформы. Формат — по [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версионирование — [семантическое](https://semver.org/lang/ru/): `MAJOR.MINOR.PATCH`.

- **MAJOR** — несовместимые изменения (ручное вмешательство при обновлении).
- **MINOR** — новые фичи, обратно совместимо.
- **PATCH** — исправления багов.

Версия зашита в образы и видна в `GET /api/health` (`"version"`) и в подвале админки.
Единый источник правды — файл [VERSION](VERSION) в корне.

## [Unreleased]

## [1.0.0] — 2026-06-11

Первый версионированный релиз. Зафиксировано как `1.0.0` то, что уже работает на
институте, плюс новые доработки, накопленные в этой итерации.

### Added
- Флаг «книга института» (`is_institute_book`) при добавлении/редактировании книги.
- Метрика «Книги института» на дашборде статистики.
- Сквозная версионность: файл `VERSION`, версия в `/api/health` и в админке,
  образы тегируются версией (не `latest`).
- Документ [docs/UPDATE.md](docs/UPDATE.md) — пошаговый флоу обновления инстанса.

### Changed
- `make-offline-bundle.sh` тегирует образы версией из `VERSION` и кладёт версию в bundle;
  имя архива содержит версию.
- `install.sh` синхронизирует `TAG` в `.env` с версией bundle при установке и обновлении
  — устраняет ситуацию, когда `--update` поднимал старые образы.
